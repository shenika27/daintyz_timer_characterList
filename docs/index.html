스킨 빌더 로그인

등록된 계정으로 로그인하면 캐릭터 타이머 스킨 빌더를 사용할 수 있습니다.

🎨 my mini timer

아래 항목을 채우고 [⬆ 자동 업로드]를 누르면 끝입니다.
배치·등록은 자동으로 처리돼요. (또는 [⬇ zip 만들기]로 받아 [📤 직접 업로드])

1. 기본 정보

skinId는 테마의 고유 ID입니다. 영문·숫자·_만 쓸 수 있고, 한 번 정하면 바꾸지 마세요.
기존 ID로 다시 만들면 그 테마를 덮어씁니다(= 수정).

개별 구매로만 풀리는 특별 테마로 표시됩니다(이용권 일괄해금 대상에서 제외).

상점 목록에서 빠집니다(기프트코드·링크 전용 스킨용).
이미 보유한 사용자의 창고에는 정상 표시됩니다.

업로드하면 즉시 판매가 시작됩니다. 비우면 상시 판매.
종료일을 지정하면 그날까지만 구매할 수 있고, 지나면 상점에 ‘기간만료’로 잠겨 표시됩니다(이미 보유한 사용자는 계속 사용).

2. 캐릭터 상태별 프레임

한 장이면 정지 이미지, 여러 장이면 아래 간격(ms)으로 애니메이션됩니다(미리보기로 바로 확인).
프레임은 투명 배경 PNG/WebP, 한 변 1024px 이하만 받습니다.

2-1. 특수 모션 (선택)

작동(running) 중 N분마다 M초 동안 잠깐 끼어드는 모션입니다(예: 10분마다 5초 물 마시기). 스킨마다 자유롭게 정할 수 있어요.
프레임을 올리고 아래 주기·길이를 둘 다 채우면 적용됩니다. 안 쓰려면 셋 다 비우세요.
화면이 켜져 있을 때만 보입니다.

3. 타이머 디자인

모든 테마는 타이머 디자인을 포함합니다(필수). 배경·버튼·숫자 폰트를 지정하세요.
비워둔 항목은 앱 내장 기본값으로 대체됩니다.

타이머 배경 PNG

박스·구분선이 모두 그려진 한 장. 가로 레이아웃(시간 좌 / 버튼 우) 기준.
없으면 앱 내장 박스로 대체됩니다.

버튼 그림 (선택)

올리지 않은 버튼은 앱 기본 기호로 표시됩니다.
play/pause는 시작·일시정지 상태에 따라 자동으로 바뀝니다.

숫자 폰트 (선택)

.ttf를 올리면 숫자를 그 폰트로 렌더링합니다(이때 크기는 영역에 맞춰지고 sizeSp는 무시).
색만 바꾸려면 폰트는 비우고 색만 지정하세요.

4. 대표 썸네일

썸네일은 필수입니다(상점 목록·타이머 탭에 뜨는 대표 이미지).
상세화면의 행동별 미리보기는 위 프레임에서 자동 생성됩니다.

썸네일 (thumb.png)

상점 카드·타이머 탭에 뜨는 대표 1장.
정사각형 권장(아니면 경고), 한 변 1024px 이하.

코드발급

기프트/해금 코드

앱 설정의 기프트코드에 입력할 코드를 만듭니다.
평생이용권 또는 개별 테마를 선택해 JSON을 만든 뒤 _inbox에 업로드하세요.

코드는 영문·숫자·-만 쓸 수 있습니다.
저장 파일에는 SHA-256 해시만 들어가니, 만든 코드는 따로 안전하게 보관해 주세요.
개별 테마 코드는 catalog의 해당 skinId에 병합됩니다.
