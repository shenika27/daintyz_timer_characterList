1. 수집하지 않는 정보

본 앱은 이름, 이메일, 전화번호, 위치, 연락처, 사진, 광고 ID를 수집하지 않습니다. 로그인·광고·사용자 행동 분석 기능 및 관련 SDK를 포함하지 않습니다.

2. 처리하는 정보와 목적

  • 구매 정보: 유료 테마 또는 평생이용권 이용 시 Google Play 구매 토큰을 개발자 서버(Cloudflare Workers)와 Google Play Developer API로 전송하여 구매 상태를 검증하고 보호된 테마 파일을 제공합니다. 개발자는 카드·계좌 정보에 접근하지 않으며 구매 토큰 원문을 데이터베이스에 저장하지 않습니다.
  • 기프트 코드 정보: 사용자가 입력한 기프트 코드는 서버에서 SHA-256 해시로 변환해 유효성을 확인합니다. 코드 원문은 저장하지 않습니다. 1회 사용 코드의 해시, 사용 횟수와 사용 시각은 중복 사용 방지를 위해 저장합니다. 교환 후 발급된 서명 토큰은 기기에 저장되고 보호된 테마를 받을 때 서버로 전송됩니다.
  • 진단 정보: 사용자가 동의하거나 설정에서 직접 전송한 경우에만 앱 버전, 기기 모델, Android 버전, 전송 사유, 최근 타이머 상태 이벤트와 오류 내용을 저장하여 문제 해결에 사용합니다. 전송 성공 시 앱에 보고서 ID를 표시합니다.
  • 서비스 오류와 남용 방지 정보: 카탈로그 오류 발생 시 파일 주소, 오류 메시지와 제한된 응답 내용을 개발자 알림으로 전송할 수 있습니다. 구매·기프트 토큰 또는 접속 IP 원문은 저장하지 않고 레이트리밋용 SHA-256 해시만 저장합니다.
  • 앱·기기 무결성 정보: 진단 요청이 Google Play에서 배포한 정상 앱과 정상 기기에서 생성됐는지 확인하기 위해 Play Integrity API를 사용합니다. 요청 해시, 앱 패키지·버전·서명, Play 라이선스 상태와 기기 무결성 판정을 문제 진단 요청의 보안 확인에만 사용하며 사용자나 기기를 추적하는 데 사용하지 않습니다.

3. 기기에 저장되는 정보

타이머 설정, 내려받은 테마, 구매·기프트 해금 상태와 서명 토큰은 앱 내부 저장소에 저장됩니다. Play 구매 토큰과 기프트 토큰은 구매 복원 및 보호 콘텐츠 요청에 사용될 수 있습니다. 기기 내 정보는 앱을 삭제하면 함께 삭제됩니다.

4. 보관 및 삭제

  • 진단 보고서: 수집일로부터 최대 90일 후 자동 삭제
  • 다운로드·개발자 알림 레이트리밋용 비식별 해시: 마지막 윈도우 시작 후 최대 48시간 보관
  • 1회 기프트 코드의 해시·사용 기록: 중복 사용 차단과 부정 이용 방지를 위해 해당 코드 정책을 유지하는 동안 보관
  • 구매 토큰 원문과 기프트 코드 원문: 데이터베이스에 저장하지 않음

진단 보고서의 조기 삭제를 원하는 경우 전송 후 표시된 보고서 ID와 함께 아래 이메일로 요청할 수 있습니다. 계정 기능이 없으므로 삭제할 계정 정보는 없습니다.

6. 전송 보안

모든 외부 통신은 HTTPS로 암호화됩니다. 구매 토큰과 기프트 토큰은 URL이 아닌 요청 본문으로 전송하며 로그에 원문을 기록하지 않습니다.
