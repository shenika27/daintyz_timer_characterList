개인정보처리방침

캐릭터 타이머 위젯 · 최종 수정일: 2026-08-27

1. 수집하지 않는 정보

본 앱은 다음을 수집하지 않습니다: 이름, 이메일, 전화번호, 위치, 연락처, 사진, 기기 식별자(광고 ID 포함), 사용 분석. 로그인 기능이 없으며, 광고 SDK·분석 SDK를 포함하지 않습니다.

2. 처리하는 정보와 목적

  • 구매 정보(구매 토큰): 유료 테마/이용권 구매 시, Google Play가 발급한 구매 토큰을 개발자의 검증 서버(Cloudflare Workers)로 전송하여 구매가 유효한지 확인하고 보호된 콘텐츠(테마 파일)를 제공하는 용도로만 사용합니다. 결제 자체는 Google Play가 처리하며, 본 앱은 카드·계좌 정보에 접근하지 않습니다.
  • 진단 정보: 사용자가 전송에 동의하거나 설정에서 직접 전송한 경우 앱 버전, 기기 모델, Android 버전, 최근 타이머 상태 이벤트와 오류 내용을 개발자 서버 (Cloudflare Workers)에 저장하여 문제 해결에 사용합니다. 카탈로그 파일 손상 시에는 파일 주소, 오류 메시지와 응답 일부를 개발자 알림 서버로 전송합니다.
  • 앱·기기 무결성 정보: 진단 업로드가 변조되지 않은 정식 앱에서 이루어졌는지 확인하기 위해 Google Play Integrity API를 사용합니다. 이 과정에서 Google Play는 요청 해시, 앱 패키지·버전·서명 정보, Play 라이선스 상태와 기기 무결성 판정에 필요한 정보를 처리합니다. 개발자는 이를 사용자나 기기를 식별·추적하는 데 사용하지 않습니다.

3. 기기에만 저장되는 정보

타이머 설정, 보유 테마 목록, 선물코드 해금 내역 등은 기기 내부 저장소에만 저장되며 외부로 전송되지 않습니다. 앱 삭제 시 함께 삭제됩니다.

4. 제3자 처리 위탁 / 공유

  • Google LLC (Google Play): 결제 처리, 구매 검증 및 Play Integrity 기반 앱·기기 무결성 확인.
  • Cloudflare, Inc.: 구매 토큰 검증 서버, 보호 콘텐츠 전송, 진단 알림 중계.

본 앱은 데이터를 광고 목적으로 공유하거나 판매하지 않습니다.

5. 전송 보안

모든 외부 통신은 HTTPS로 암호화됩니다.

6. 아동

본 앱은 아동을 주 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
